# Code of Conduct

## Our pledge

We want this project to be a welcoming, harassment-free place for
everyone, regardless of background or experience level. Contributors
and community members are expected to be kind, patient, and
constructive — especially with newcomers asking basic questions.

## Expected behaviour

- Be respectful and assume good faith.
- Critique code and ideas, never people.
- Keep discussions on-topic and helpful.
- Accept feedback gracefully; offer it specifically.

## Unacceptable behaviour

- Harassment, insults, or discrimination of any kind.
- Publishing anyone's private information (including real API keys —
  yours or anyone else's).
- Spam, scams, or impersonation.

## Enforcement

Maintainers may remove comments, issues, or contributions that violate
this code, and may block repeat offenders. Report problems through the
channels in `README.md`. This text is adapted from the Contributor
Covenant, version 2.1.
